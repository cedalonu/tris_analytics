# Phase 60 — Decision version comparison
- Compares the latest snapshot for each candidate under two explicitly recorded eligibility configurations.
- Baseline and comparison are computed on identical imported histories. Summaries count eligibility changes, gaining/lossing eligibility, queue changes, score changes and high-priority transitions.
- Rows show both states and change category; no evaluation timestamp is fabricated.
- This is a sensitivity/stability review tool. It does not estimate outcomes or predictive advantage.
